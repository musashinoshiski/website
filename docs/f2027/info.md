# スキーフェスティバル

令和8年度 武蔵野市民スポーツ大会（春季大会）

- 主催 武蔵野市、武蔵野市教育委員会、武蔵野市スポーツ協会
- 主管 武蔵野市スキー連盟

“スキーコンテスト”＆申告タイムレースの2本立て！菅平スキー場で初級者から上級者まで楽しめます！！\
大回り、小回り、ポールなど、様々な種目でテクニックを磨いてみませんか？\
採点は、元・SAJデモのカリスマ講師が、公正に親切にジャッジを行います。\
参加はスキー経験のある方（中斜面を安全におりることができれば参加可）が対象ですが、初級者でも一発逆転の申告タイムレースも行われます。\
バッジ検定とは一味違う競技会“スキーコンテスト”でスキーの新しい楽しさを発見できます。\
また、応援参加も可能ですので、お誘い合わせの上、大勢で参加しフェスティバルで盛り上がりましょう！
